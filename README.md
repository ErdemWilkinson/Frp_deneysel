# Frp_deneysel — D&D AI Game Master

A single-player, chat-based **D&D RPG simulator** with a tactical grid. The player creates a character, an AI-powered Game Master (GM) drives the narration, and combat plays out on a tactical grid during enemy encounters.

> 🚧 Work in progress — features and structure are subject to change.

## Concept

- The player creates a character (race/class selection, name)
- The **Game Master (GM)** narration is generated by the Google Gemini API
- If no API key is set, or the request errors, times out, or hits a quota limit, the game falls back to pre-written, rule-based template text instead of AI narration
- **Character sheet:** HP, mana, attributes, inventory (use / equip / drop / throw)
- **Tactical grid map:** token movement, obstacles, loot, turn-based system
- The tactical grid only appears when an enemy is present; otherwise the game auto-switches to a full-screen chat/text mode

## Scope

Currently focused solely on the **D&D universe** (other settings like Star Wars or Naruto may be added later, but are out of scope for now).

## Stack

| Layer | Technology |
|---|---|
| Frontend | React + Vite (TypeScript) |
| Backend | Node.js + Express |
| AI GM | Google Gemini API |

The repo root contains `frontend/` and `backend/` directories.

## Getting Started

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev
```

You'll need to add your own Gemini API key to a `.env` file. Without a key, the GM uses the fallback template text instead.
